# 🚀 Gowthama's AI Engineer Portfolio

A premium, interactive, and recruiter-focused portfolio website for **Gowthama Shanmugam V**.

## ✨ Features

- **Dark Mode UI**: Sleek Cyberpunk theme with Deep Slate and Neon accents.
- **Glassmorphism**: Modern glass cards with `backdrop-filter` blur.
- **AI-Themed Background**: Dynamic neural network particle system.
- **Interactive Chatbot**: Simulates an AI assistant to answer questions.
- **Smooth Animations**: Powered by AOS (Animate on Scroll) and CSS transitions.
- **Typing Hero**: Dynamic hero section with fading/typing effects.
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop.
- **Recruiter Focused**: Ready-to-go resume download and contact form.

## 🛠 Tech Stack

- **HTML5 & CSS3** (Vanilla)
- **JavaScript** (ES6+)
- **Libraries**:
    - [Particles.js](http://vincentgarreau.com/particles.js/) (Background)
    - [AOS](https://michalsnik.github.io/aos/) (Scroll Animations)
    - [Typed.js](https://github.com/mattboldt/typed.js) (Typing Effect)
    - [FontAwesome](https://fontawesome.com/) (Icons)

## 🚀 How to Deploy on Vercel

1. Push these files to a fresh **GitHub Repository**.
2. Connect your repo to **Vercel** ([Vercel Dashboard](https://vercel.com/new)).
3. Vercel will automatically detect the static project and deploy it.
4. Ensure `Gowthama_Shanmugam_V_Resume.pdf` is in the root directory for the download link to work.
